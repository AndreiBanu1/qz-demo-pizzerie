# Pizza Mița (demo)

A demo website for a fictional Romanian pizzeria, built by [Quality Zone](https://qualityzone.netlify.app/ro) to show a before/after quality audit.

This branch is the deliberately weak "before" build. It contains planted issues, each marked with a `PLANTED P-xx` comment, which are audited and then fixed.

Pizza Mița is not a real business. The address, phone number and hours are placeholders.

## Commands

- `npm run dev` starts the dev server
- `npm run build` builds into `dist/` and writes `dist/version.json`
- `npm test` runs the unit tests
